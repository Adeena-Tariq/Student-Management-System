# 🎓 Student Data Management System (SDMS)

A console-based Student Data Management System developed in **C++** for efficiently managing student records, academic performance, attendance, and administrative operations. The system provides secure admin access, automated grade calculation, sorting features, and persistent file storage.

---

## 🚀 Features

- 🔐 Secure Admin Login
- 👨‍🎓 Student Registration System
- 📚 Marks Entry for Multiple Subjects
- 📊 Automatic Grade Calculation
- 📈 Student Record Sorting
- 📋 Attendance Management
- 📂 File Handling & Data Persistence
- ✅ Input Validation & Error Handling

---

## 🛠️ Technologies Used

- **Language:** C++
- **Concepts:** Arrays, Dynamic Memory Allocation, File Handling, Functions, Sorting Algorithms, Input Validation
